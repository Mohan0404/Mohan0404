<summary><b>&nbsp;📚&nbsp; NexusRAG — AI Knowledge Assistant</b> &nbsp;—&nbsp; Python · FastAPI · LangChain · ChromaDB · Redis </summary>

<br/>

A **RAG-based knowledge assistant** that answers questions from ingested documents, with source citations. The FastAPI backend handles document ingestion, chunking, embedding, and vector retrieval, then passes the retrieved context to an LLM to generate grounded answers.

| Attribute | Detail |
|:---|:---|
| **Workflow** | Document ingestion → chunking → embeddings → ChromaDB retrieval → LLM answer with citations |
| **Backend** | FastAPI REST endpoints · Pydantic validation  |
| **LLM Integration** | Gemini and OpenRouter via LangChain |
| **Caching** | Redis query caching to avoid repeated work on identical queries |
| **Tech Stack** | Python · FastAPI · LangChain · ChromaDB · Redis · Gemini · OpenRouter |
